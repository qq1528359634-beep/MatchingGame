# Matching Game (どうぶつ絵文字神経衰弱)

**WPF (Windows Presentation Foundation)** をベースに開発された、シンプルな記憶力トレーニング（神経衰弱）ゲームです。プレイヤーは記憶を頼りに、最短時間ですべてのペアを見つけることを目指します。

## 🎮 ゲームの遊び方

1. **ゲーム開始**: アプリを起動すると、8種類のどうぶつ絵文字（計16個）がランダムにシャッフルされて配置され、タイマーが自動的にスタートします。
2. **ペアを見つける**:
   - 1つ目のブロックをクリックすると、そのブロックが一時的に非表示になります。
   - 2つ目のブロックをクリックします：
     - **絵文字が一致した場合**: ペア成立となり、両方のブロックが消えます。
     - **絵文字が不一致の場合**: 1つ目のブロックが再び表示されます。
3. **ゲームクリア**: すべてのペア（8組、計16個）を消すとタイマーが停止します。
4. **もう一度遊ぶ**: クリア後、画面下部のタイマーテキストをクリックすると、新しいゲームが再スタートします。

## ✨ 主な機能と技術的特徴

- **WPF UI フレームワーク**: `Grid` と `TextBlock` を使用して、シンプルで視認性の高い画面を構築。
- **ランダムシャッフルアルゴリズム**: `System.Random` と `List.RemoveAt` を組み合わせ、毎ゲーム完全にランダムで公平な配置を実現。
- **リアルタイムタイマー**: `DispatcherTimer` を利用し、0.1秒刻みの高精度なタイムをリアルタイムに画面へ反映。
- **スコアのローカル保存**: ゲームクリア時、現在のシステム日時とクリアタイムをフォーマット化し、実行フォルダ内の `time_record.txt` に自動で追記保存します。

## 🛠️ 開発環境 / 技術スタック

- **開発言語**: C# 10+
- **フレームワーク**: .NET 6.0 / 7.0 / 8.0 (WPF)
- **開発ツール**: Visual Studio 2022

## 📂 ファイル構成（主要部分）

- `MainWindow.xaml.cs`：ゲームのメインロジック（初期化、シャッフル、クリック判定、タイマー処理、ファイル書き込み）。
- `time_record.txt`：自動生成されるスコア記録ファイル（ビルドディレクトリの `bin\Debug\...` 内に作成されます）。
  - *記録例*: `2026/06/14 14:42:00-15.4s`

## 🚀 実行方法

1. リポジトリをクローンまたはダウンロードします。
2. **Visual Studio 2022** でプロジェクトファイル（`.csproj` または `.sln`）を開きます。
3. **「デバッグ開始」 (F5)** ボタンを押して、ビルドおよびゲームを実行します。
