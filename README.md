# 🐾 Animal Emoji Matching Game

## 概要

**Animal Emoji Matching Game** は、Windows向けのWPFデスクトップゲームです。
16枚のパネルに隠された動物の絵文字をめくり、同じペアを8組すべて見つけることを目指す**Matchingゲーム**です。クリアタイムが自動的にファイルに記録されます。

---

## ゲーム内容

- 4×4のグリッドに8種類の動物絵文字がランダムに配置される
- パネルをクリックして絵文字を表示し、同じ絵文字を2枚続けてめくればペア成立
- ペアが揃わなかった場合は自動的に裏返る
- 8ペアすべて揃えるとゲームクリア

### 登場する動物

| 絵文字 | 動物 |
|--------|------|
| 🦜 | オウム |
| 🦖 | ティラノサウルス |
| 🐬 | イルカ |
| 🐋 | クジラ |
| 🦆 | アヒル |
| 🐈 | ネコ |
| 🦢 | ハクチョウ |
| 🐀 | ネズミ |

---

## 主な機能

- **タイマー計測**：ゲーム開始と同時に0.1秒単位でタイムを計測
- **タイム記録の保存**：クリア時に `time_record.txt` へ日時とタイムを自動保存
- **リスタート**：クリア後にタイマー表示をクリックするとゲームをリセット・再開

## 使い方

1. アプリを起動するとゲームが自動的に始まります
2. パネルをクリックして絵文字を表示します
3. 同じ絵文字が2枚揃えばペア成立、消えます
4. 揃わなければ裏返ってやり直し
5. 8ペアすべて揃えるとクリア、タイムが保存されます
6. タイマー表示をクリックするとリスタートできます

---

## タイム記録について

クリア時、実行ファイルと同じフォルダに `time_record.txt` が自動生成されます。

記録の形式：
```
2026/06/14 15:30:22 - 12.3s
2026/06/14 15:32:10 - 9.8s
```

## プロジェクト構成

```
MatchingGame/
├── MainWindow.xaml        # UI レイアウト（4×4グリッド）
├── MainWindow.xaml.cs     # ゲームロジック全般
└── time_record.txt        # クリア記録（実行後に自動生成）
```

### 主要な変数・メソッド

| 名前 | 役割 |
|------|------|
| `tenthsOfSecondsElapsed` | 経過時間（0.1秒単位） |
| `matchesFound` | 現在のペア成立数 |
| `SetUpGame()` | 絵文字をランダム配置してゲーム初期化 |
| `TextBlock_MouseDown()` | パネルクリック時のマッチング判定 |
| `Timer_Tick()` | タイマー更新・クリア判定・記録保存 |
